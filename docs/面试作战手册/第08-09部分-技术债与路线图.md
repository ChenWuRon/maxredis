# 第九部分：4 周上线路线图

> 原则：先正确性/可观测，后性能/扩展。每周以"发布门禁清单"收口。

## Week 1——止血（只做正确性）
- **P0-1** 接线 SnapshotReceiver：leader 侧触发 → 3 节点间快照全链路打通 → 新增"落后 10 万条自动快照追赶"集成测试。
- **P0-2** 真实 3 节点 Docker Compose（raft_dir 全开、全 fsync 默认），手工演练 kill -9 / 分区 / 重启恢复。
- **P0-3** CMake reconfigure 全量构建：raft_cluster_test、raft_codec_test 跑起来，ctest 大盘归位。
- **P0-4** AOF 决策会：raft 模式删 AOF / 独立模式补 fsync+EXPIRE，拍板并落文档。
- **门禁**：3 节点 kill -9 任一节点 → 16s 内恢复服务且无丢已 ACK 写。

## Week 2——持久化审计与可观测
- **P1-7** 全链路 fsync 返回检查（manifest/snapshot_meta/apply_progress/raft_storage）统一 RAII。
- **P1-8/P1-9** raft_engine 的 static_cast UB 与 Encode 直写补防。
- **P2-11/12** INFO 真实化第一版（commit 数、fsync 数、lease 状态机）+ log_gap/snapshot flag 参数化。
- **P1-10** 快照加载 CRC；发送短读断言。
- **门禁**：周一 CI 全绿；信息面板能看到每个节点的 next/match/commit/lease 实时值。

## Week 3——一致性深水区
- **P1-4** WaitForApplied：超时 → 返回重试错误，绝不返回陈旧值（配套 10 个线性化测试，含 5s 超时用例）。
- **P1-5** Memcached store 修复 + 协议测试入库。
- **P1-6** 并行心跳落地，压测 8 节点选举抖动 Δterm 直方图归零。
- **新增**：EXPIRE 淘汰器（惰性→定期）与快照派生一致性测试。
- **门禁**：报名的 270 用例 + 新增 50 用例全绿；3 节点压测 30 分钟无 term 抖动。

## Week 4——验收收口
- **P3-17/18/19**：文档同步（选举/队列参数）、bench harness 脚手架（可复现 40K/54us/63 万三档数字）、FileLogStorage 退役决策。
- **P2-13/14/15**：ENOBUFS 背压、buf_ring 默认开、reply_builder 阈值 flush。
- **P2-20**：multi-group 接线设计评审（本周只出设计：槽位迁移 + 组选举并行 + 跨组无事务约束）。
- **收口**：技术债台账 20→≤6；写"上线前检查单"（README 化，含默认参数表）；给校招/P5/P6 共享的最终版 3/5/10 分钟讲稿（见第十二部分）。
